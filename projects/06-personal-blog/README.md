# Personal Blog

A server-rendered personal blog platform built with Node.js.

## Overview

This project provides a lightweight blog app with a home feed, single post views, and an admin dashboard for creating and deleting blog posts. Posts are stored in a local `posts.json` file.

## Features

- Home page that lists published blog posts
- Single-post detail view
- Admin dashboard for creating and deleting posts
- File-based persistence using `posts.json`
- Runs locally on port `3000`

## Requirements

- Node.js 16 or later

## Install

From the `projects/06-personal-blog` directory:

```bash
npm install
```

## Run

```bash
npm start
```

Then open your browser to:

```text
http://localhost:3000
```

## Usage

1. Open the app in your browser.
2. Visit the Admin Dashboard at `/admin`.
3. Create new posts using the form.
4. View published posts from the home feed.
5. Click a post title to read the full entry.
