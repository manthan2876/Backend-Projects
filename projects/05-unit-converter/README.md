# Unit Converter

A simple web-based unit converter built with Node.js.

## Overview

Convert values across length, weight, and temperature units using a lightweight HTTP server. The app renders a browser form and performs conversions on submit.

## Features

- Length conversion: meter, centimeter, millimeter, kilometer, inch, foot, yard, mile
- Weight conversion: kilogram, gram, milligram, pound, ounce
- Temperature conversion: Celsius, Fahrenheit, Kelvin
- Simple browser interface with navigation tabs for each conversion type
- Runs locally on port `3000`

## Requirements

- Node.js 16 or later

## Install

From the `projects/05-unit-converter` directory:

```bash
npm install
```

## Run

```bash
npm start
```

Then open your browser to:

```text
http://localhost:3000
```

## How to Use

1. Open the app in your browser.
2. Choose the conversion category: Length, Weight, or Temperature.
3. Enter a numeric value.
4. Select the source unit and target unit.
5. Submit the form to see the converted result.
