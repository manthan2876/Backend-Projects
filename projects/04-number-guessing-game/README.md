# Number Guessing Game

A simple CLI number guessing game built with Node.js.

## Overview

Choose a difficulty level and try to guess a secret number between 1 and 100. The game tells you whether your guess is too high or too low and tracks the remaining attempts.

## Features

- Difficulty levels: Easy (10 attempts), Medium (5 attempts), Hard (3 attempts)
- Interactive command-line prompts
- Higher/lower feedback for each guess
- Win/loss summary with the secret number

## Requirements

- Node.js 16 or later

## Install

From the `projects/04-number-guessing-game` directory:

```bash
npm install
```

## Run

```bash
npm start
```

Or:

```bash
node index.js
```

## How to Play

1. Start the game.
2. Enter a difficulty choice: `1`, `2`, or `3`.
3. Guess a number between 1 and 100.
4. The game will tell you if the secret number is higher or lower.
5. Keep guessing until you win or run out of attempts.
